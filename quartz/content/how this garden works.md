I write these notes in [Obsidian](https://obsidian.md), a markdown note-taking app. When I save, they sync to GitHub and this site rebuilds automatically — so the garden stays in sync with my thinking without any manual publishing.

The site is built with [Quartz](https://quartz.jzhao.xyz/) and lives at `leahtu.github.io/garden`.
